# Weekly Summary Evals

This folder contains a lightweight eval dataset and runner focused on the Markdown output of `generate_weekly_summary()`.

## Contents

- `weekly_summary_dataset.jsonl` — JSONL dataset with fixed `metrics`, `anomalies`, and `context` inputs plus expected outputs and rubrics.
- `run_weekly_summary_eval.py` — Runner that generates summaries with the same prompt logic as `generate_weekly_summary_llm`, then submits grading to the OpenAI eval platform.
- `weekly_summary_eval_results.json` — Output file generated by the runner (created after running).

## Running the eval

```bash
export OPENAI_API_KEY=your-key
export OPENAI_MODEL=gpt-4.1-mini
export OPENAI_EVAL_MODEL=gpt-4.1-mini

PYTHONPATH=src python evals/run_weekly_summary_eval.py \
  --dataset evals/weekly_summary_dataset.jsonl \
  --model gpt-4.1-mini \
  --grading-model gpt-4.1-mini \
  --eval-name weekly-summary-markdown-eval \
  --run-name weekly-summary-run
```

The script will:
1. Generate a weekly summary for each dataset item using the same prompt construction as `generate_weekly_summary_llm()`.
2. Create an eval group with three score-model graders:
   - **format_correctness**
   - **grounding_to_metrics**
   - **actionable_recommendations**
3. Submit a JSONL run with the model outputs as samples.
4. Fetch per-case scores from the eval platform and write them to `evals/weekly_summary_eval_results.json`.

## Notes

- If you want different grading criteria or ranges, update `build_grading_criteria()` in `run_weekly_summary_eval.py`.
- The dataset includes both an example expected summary and rubric text. Graders use the rubric fields when scoring.
